8086 Programs

1. Largest Number in Array

AIM: Write a program to find the largest number in an array.

MOV WORD PTR[1000H],0002H MOV WORD PTR[1002H],001AH MOV WORD PTR[1004H],0004H MOV WORD PTR[1006H],009AH MOV WORD PTR[1008H],0021H MOV BX,1000H MOV CL,05H MOV AX,[BX] DEC CL BACK: ADD BX,2 CMP AX,[BX] JNC SKIP MOV AX,[BX] SKIP: DEC CL JNZ BACK MOV [0020H],AX HLT
Output: Largest number = 009AH

2. Fibonacci Series

AIM: Write a program to generate Fibonacci series.

MOV AL,00H MOV SI,1000H MOV [SI],AL ADD SI,01H ADD AL,01H MOV [SI],AL MOV CX,0008H SUB CX,02H L1: MOV AL,[SI-1] ADD AL,[SI] ADD SI,01H MOV [SI],AL LOOP L1 HLT
Output: 0, 1, 1, 2, 3, 5, 8, 13...

3. ASCII Division (15 ÷ 6)

AIM: Write a program to divide ASCII numbers 15 by 6.

MOV AL,"5" MOV AH,"1" SUB AL,30H SUB AH,30H AAD MOV BL,"6" SUB BL,30H DIV BL ADD AX,3030H MOV DX,AX HLT
Result: Quotient = 2, Remainder = 3

Steps to Perform on Intel Kit (8085)

Procedure: Follow these steps to execute 8085 programs on Intel Kit.

Step No. Action
1Press Reset
2Press Examine Memory
3Enter starting address
4Press Next
5Enter opcodes by subsequently pressing Next
6Press Reset
7Press Examine Memory
8Enter 1st input address
9Press Next
10Enter inputs
11Press Next
12Repeat Step 10 and 11 for more inputs
13Press Reset
14Press Go
15Enter starting address of the program to compile
16Press EXEC / FILL
17Press Reset
18Press Examine Memory
19Enter Output Address
20Press Next
Note: These are the standard operating steps for running and checking output of 8085 assembly programs on Intel Trainer Kit.
